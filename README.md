# خيرات دجبية — Khayrat Dijbia

موقع تجارة إلكترونية حديث لبيع المنتجات التونسية التقليدية المجففة عبر WhatsApp

## 🎯 المميزات

✨ **تصميم حديث وسريع** - واجهة مستخدم جميلة وسهلة الاستخدام
🌐 **دعم اللغة العربية الكامل** - تطبيق موجه من اليمين إلى اليسار (RTL)
📱 **متجاوب تماماً** - يعمل بشكل مثالي على الهاتف والتابلت والحاسوب
🛒 **سلة تسوق سهلة** - اختيار الكمية وحساب السعر الإجمالي تلقائياً
💬 **تكامل مع WhatsApp** - إرسال الطلبات مباشرة عبر واتساب
🎨 **عروض وخصومات** - عرض المنتجات مع الأسعار القديمة والخصومات
🔍 **تصفية المنتجات** - البحث بين الكل أو العروض فقط
⚡ **خفيف وسريع** - لا يحتاج إلى قاعدة بيانات معقدة

## 📁 هيكل المشروع

```
khayrat-dijbia/

```

## 🚀 البدء السريع

### 1. استنساخ المشروع

```bash
git clone https://github.com/youssefdjebbi/khayrat-dijbia.git
cd khayrat-dijbia
```

### 2. تخصيص الإعدادات

افتح ملف `config.js` وعدّل البيانات التالية:

```javascript
const STORE_CONFIG = {
  storeName: 'خيرات دجبية',           // اسم المتجر
  whatsappNumber: '21650000000',       // رقم واتساب (بدون +)
  
  contact: {
    phone: '+216 50 000 000',          // رقم الهاتف
    email: 'info@khayrat-dijbia.tn',   // البريد الإلكتروني
    address: 'دجبة، تونس',             // العنوان
  },
  
  social: {
    facebook: 'https://facebook.com/...',    // فيسبوك (اختياري)
    instagram: 'https://instagram.com/...', // إنستجرام (اختياري)
    tiktok: 'https://tiktok.com/...',      // تيك توك (اختياري)
  },
};
```

### 3. إضافة المنتجات

في ملف `config.js`، أضف منتجاتك:

```javascript
const PRODUCTS = [
  {
    id: 1,
    name: 'اسم المنتج',
    category: 'الفئة',
    price: 12.5,                    // السعر الحالي
    oldPrice: 15.0,                 // السعر السابق (اختياري)
    image: 'https://...',           // رابط الصورة
    description: 'وصف المنتج',
    discount: 15,                   // نسبة الخصم (اختياري)
  },
  // أضف المزيد من المنتجات...
];
```

### 4. نشر الموقع

يمكنك نشر الموقع مجاناً على:

- **GitHub Pages** (الأسهل)
- **Netlify**
- **Vercel**
- **أي استضافة ويب عادية**

#### نشر على GitHub Pages:

1. اذهب إلى إعدادات المستودع
2. انتقل إلى "Pages"
3. اختر الفرع الرئيسي (main)
4. حفظ
5. سيكون الموقع متاحاً على: `https://yourusername.github.io/khayrat-dijbia`

## 🎨 التخصيص

في ملف `style.css`، عدّل متغيرات الألوان في الأعلى:

